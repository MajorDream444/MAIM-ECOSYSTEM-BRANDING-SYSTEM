DESIGN PRINCIPLE

Every page has ONE job.

Remove friction. One clear CTA per page. If a section doesn't move them to the next step, cut it.

The universal section stack.

THE THREE RULES
1. One promise above the fold.
2. One CTA, repeated — never competing.
3. No outbound links that leak the funnel.
DROP, DON'T ADD

A webinar page may only need A·B·C·G. A cohort sales page uses all eight. Start from the full stack and remove anything that doesn't push to the one action.
