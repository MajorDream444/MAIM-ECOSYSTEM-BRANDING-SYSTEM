01 Vault Doctrine

Content is rented. IP is owned.

Every post on a platform is a tenant on someone else's land. The Vault is the deed. We make one thing — a broadcast, a lesson, a drop — and we never let it leave as a single disposable post again.

THE PRINCIPLE
Make once.

Every creation enters the Vault the moment it exists — raw, captioned, tagged. Nothing is "just a livestream."

THE PRINCIPLE
Own forever.

Rights, source files and metadata travel with the asset. The platform can disappear; the IP cannot.

THE PRINCIPLE
Reuse endlessly.

One asset feeds clips, carousels, workbooks, merch and licensing. Value compounds with every reuse.

THE LIFECYCLE · IDEA → ASSET → IP → VAULT → REUSE → REVENUE
01 · IDEA
A thought worth teaching is logged before it's filmed.
02 · ASSET
Captured as a file: video, audio, doc, design, concept.
03 · IP
Tagged with owner, rights and licence class.
04 · VAULT
Stored, versioned and searchable in one source of truth.
05 · REUSE
Re-cut, re-skinned and re-published across every channel.
06 · REVENUE
The payoff layer — built later through Hanzo / Lux.
BOUNDARY

MAIM 09 is the asset / IP system — not the store. No payment rails, no tokenized access, no checkout. Commerce, licensing automation and access control are built later through Hanzo / Lux. This board makes the IP ready for that day.

04 Transcript + Clip Pipeline

Long-form in. Many forms out.

A repeatable five-stage flow turns one recording into a transcript, then into every short, written and social derivative — each one tagged back to its source.

STAGE 01
Capture
Raw recording lands in the EP folder, untouched master preserved.
STAGE 02
Transcribe
Speech → time-coded text. The searchable backbone of the asset.
STAGE 03
Mine
Mark the moments — quotes, hooks, teachable beats, prompt-worthy lines.
STAGE 04
Cut & Write
Reels, quote cards, carousels, newsletter — produced from marked beats.
STAGE 05
File & Link
Each derivative stored, tagged, and linked to its source timestamp.

08 Access + Membership Logic

Who can reach what.

Four access tiers map cleanly onto the licence classes. This is the logic of access — the rules — not the gate. Tokenized access and enforcement are built later.

TIER 0
Public
Anyone on the internet. The top of the funnel.
→ Clips & reels
→ Quote cards
→ Free guides
TIER 1
Member
Enrolled in a cohort or community.
→ Full lessons
→ Prompt library
→ Workbooks
TIER 2
Inner Circle
Alumni, partners, build crew.
→ Source files
→ Early drops
→ Licensable IP
TIER 3
Founder
Major + core team only.
→ Reserved IP
→ Masters
→ Everything
ACCESS LOGIC · IF / THEN (RULES, NOT RAILS)
IF licence_class = open THEN visible to Tier 0+
IF licence_class = members-only THEN visible to Tier 1+
IF licence_class = licensable THEN visible to Tier 2+, deal-flagged
IF licence_class = reserved THEN Tier 3 only · sign-off required

The Vault stores these rules as metadata. Enforcing them — login walls, tokens, payments — is the commerce layer's job, not this volume's.
