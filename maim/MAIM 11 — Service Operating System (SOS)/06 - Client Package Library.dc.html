Package Name
Standard Consulting Package
Package Purpose
The baseline engagement shape: advisory scope, delivered on a single SOW, with weekly cadence through final delivery.

Sprint 10 — Custom Engagement Package

Package ID
PKG-010
Package Name
Custom Engagement Package
Package Purpose
Give MAIM a disciplined way to say yes to an unusual engagement without inventing new Templates or Workflows.
Target Client
Any client whose needs span or fall between PKG-001 through PKG-009.
Discovery Requirements
An expanded WF-001 Discovery pass specifically to identify which existing components apply.
Package Configuration
A documented selection of which PKG-001–009 elements are combined, with the exceptions noted.
Required Templates
Drawn only from the existing Template Library — no bespoke templates are created for a custom engagement.
Workflow Mapping
An explicit map of which WF-001–010 steps apply, skip, or repeat for this engagement.
Approval Requirements
Any deviation from a standard package requires sign-off via COMP-501 before the engagement begins.
