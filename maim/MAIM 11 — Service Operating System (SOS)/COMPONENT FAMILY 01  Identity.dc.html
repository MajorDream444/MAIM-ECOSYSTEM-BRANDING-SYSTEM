Identity

Components that identify a document — who wrote it, who it's for, what it is, and whether it can be trusted at a glance.

Every component inherits the MAIM 00 Brand System and the SOS Foundation Board. Nothing here redefines color, type, or iconography — each spec below is an assembly rule, not a new design.

Layout
3-zone flex row: Crown Seal + wordmark (left), document type (center-left), ID/version (right). Tri-bar closes the band, full width.
Typography
Eyebrow in JetBrains Mono 500, tracked 0.16em. Document type in Archivo Black 900, uppercase, 21px.

Compact Header

Purpose: One-line running header for interior pages. Used on: page 2+ of any multi-page document, above the fold, repeating on every sheet.

Statement of Work
DOC-2026-00417 · v2.3
Layout
Single row, 2 zones: mini-seal + document type (left), ID/version (right). No tri-bar — a hairline rule closes it instead.
Typography
Document type in Archivo 600, 12.5px, uppercase — one weight down from the Primary Header's Archivo Black.
Spacing
12px bottom padding, sits inside the page's top margin band, not the content column.
Accessibility
Repeats on every page so a reader entering mid-document is never without document identity.
Print / PDF
Bound to the running header slot — repeats automatically per printed sheet, independent of content length.

Full field set (13): Document ID, Client, Project, Document Type, Version, Status, Owner, Created, Updated, Effective, Approval State, Confidentiality, Related Artifacts.
Layout
3-column grid, label-over-value pairs. Collapses to 2 columns under 5.5in content width.
Typography
Field labels: JetBrains Mono 500, 9px, tracked, gold. Values: Archivo 400 (dates/IDs in mono) 11.5px.
Spacing
16/20px block padding, 14px row gap, 22px column gap. Gold 1px border, never a fill.
Accessibility
Missing values render as an em dash — never a blank cell — so screen readers and print never imply a data-entry error.
Print / PDF
Table-based rows carry `break-inside: avoid`; the block never splits a label from its value across a page.

Document Identifier

Purpose: The canonical Document ID stamp — the single string every header, footer, and metadata block repeats. Used on: every page, header and footer, and any cross-reference to another document.

Primary

Layout
Inline text token — never boxed, never badged. Composed as PREFIX-YEAR-SEQUENCE (e.g. DOC, PROP, SOW, INV, MSA).
Typography
JetBrains Mono 400–500 exclusively — the ID is the one place mono appears at body-reading size.
Spacing
No internal padding; sits inline with a middle-dot separator ( · ) before adjacent metadata (version, date).
Accessibility
Cross-reference variant always underlines — color (gold) is never the sole signal that it's a reference.
Print / PDF
Mono at 13px minimum in print; never abbreviated or truncated even in tight footers.

Version Badge

Purpose: Flags which revision of a document is in hand. Used on: headers, footers, metadata blocks, and version-history tables.

v2.3
v2.3 · CURRENT
v1.0 · SUPERSEDED
Layout
Small outlined tag, always adjacent to the Document Identifier, never standalone.
Typography
JetBrains Mono 400, 11px, no letter-spacing (numerals need no tracking).
Spacing
4px vertical / 12px horizontal padding; 1px border, 2px minimum gap from neighboring tags.
Accessibility
Superseded state pairs strikethrough with muted color and the word "SUPERSEDED" — never relies on color alone.
Print / PDF
Border-only badges survive grayscale print; never a filled color badge for version state.

Confidentiality Label

Purpose: States handling sensitivity. Used on: every footer, and the metadata block of client-facing and internal documents alike.

Internal Use Only
Confidential — Client & Internal
Restricted — Do Not Distribute
Layout
Plain tracked text, no container — sits centered in the footer band between Document Identifier and page number.
Typography
JetBrains Mono 500, 10px, uppercase, 0.1em tracking — matches all system labels.
Spacing
No padding; inherits the footer band's 12px top offset from the page's hairline rule.
Accessibility
Restricted level always spells out the instruction ("Do Not Distribute") rather than relying on the orange alone.
Print / PDF
Repeats on every printed page footer — a separated page never loses its handling instruction.
