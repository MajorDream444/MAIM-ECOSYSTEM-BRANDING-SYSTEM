Data

COMP-801
Primary Variant

Table

Purpose: The general-purpose data grid — not money-specific like the Financial family's Pricing Table. Used on: Reports (activity logs), Delivery Packets (asset lists), Onboarding Guides (tool inventories).

Layout
Same visual construction as the Financial family's Pricing Table — white-clarity header, hairline rows — kept as one shared table style across the system.
Typography
Header Archivo 700, 12px; text cells Archivo 400; any numeric or date cell in JetBrains Mono, right-aligned.
Spacing
9px vertical / 12px horizontal cell padding, matching Financial and Approval tables exactly.
Accessibility
Real `<thead>` markup always used; column headers never implied by bold text alone in a body row.
Print / PDF
Header repeats across a page break; rows never split mid-content.

Comparison Table

Purpose: Sets two or more options side by side against shared criteria. Used on: Proposals offering tiered packages (Starter / Growth / Enterprise).

CriteriaStarterGrowth
Monthly Hours2040
Dedicated Lead—✓
Layout
Criteria column left-aligned; each option column centered. The recommended option's column carries a 6% gold tint the full height of the table.
Typography
Recommended column header in gold; all others in muted ivory — the only differentiation in header styling.
Spacing
8/10px cell padding; never more than 4 option columns before the table should split into separate Comparison Tables.
Accessibility
Checkmark/dash cells always paired with a `<th scope>`-equivalent header association; never color-only presence/absence.
Print / PDF
The tinted recommended column remains visible in grayscale as a distinct fill weight, not just hue.

Primary Variant

KPI Card

Purpose: Surfaces one key number with a trend, for scanning across a row. Used on: Weekly Reports and Executive Summaries, typically 3–4 across a row.

Tickets Resolved
184

Avg. Response Time
3.2h

Layout
Label, large figure, trend line stacked top to bottom; equal-width cards in a flex row, never resized to fit content.
Typography
Figure in JetBrains Mono 400, 22px — the largest mono size in the system outside the Receipt Summary's Amount Paid.
Spacing
14/16px padding, 16px gap between cards, 6px figure-to-trend, 2px trend-to-baseline.
Accessibility
Trend direction stated in words ("vs. last week," "slower") and an arrow glyph — never the arrow or color alone.
Print / PDF
Row of KPI Cards never wraps mid-row across a page break — the whole row moves together.

Metric Tile

Purpose: A smaller, borderless version of KPI Card for dense grids of many metrics at once. Used on: Executive Summaries with 6+ metrics, laid out in a tight grid.

Layout
No border, no fill — label + figure only, in a 4- or 6-up grid, denser than KPI Card.
Typography
Label at 8px (the smallest text size permitted anywhere in the system); figure mono 15px.
Spacing
14px grid gap; 3px label-to-figure — the system's tightest metric pairing.
Accessibility
Because of its small label size, Metric Tile is never used for a number requiring urgent attention — that's Deadline Callout or Outstanding Balance's job.
Print / PDF
8px label is the system's print-size floor — never set smaller even under space pressure.
COMP-805
Primary + Alternate

Progress Indicator

Purpose: A compact, non-linear alternative to the Timeline family's Progress Bar — for step counts rather than percentages. Used on: Onboarding Guides ("Step 3 of 6") and multi-stage checklists.

Step 3 of 5
Layout
Discrete segments, one per step — never a continuous bar, which belongs to the Timeline family's Progress Bar instead.
Typography
"Step N of M" label always accompanies the segments in mono 10px — segments never stand alone.
Spacing
6px gap between segments; 10px between segment row and label.
Accessibility
Current step is gold, completed steps ivory, remaining steps muted — the text label is the authoritative source, colors are reinforcement.
Print / PDF
Segment count and label always match exactly — never rounded or approximated in a printed copy.

Primary Variant

Chart Container

Purpose: The frame every chart or graph sits inside — this component defines the frame, not the chart itself. Used on: Reports and Executive Summaries wherever a real data visualization is supplied.

Jun 1 – Jul 8

Layout
Title + date range header, chart area, source caption footer — the chart itself is supplied per document, never hand-drawn as decoration.
Typography
Title Archivo 600, 13px; date range and source caption in mono, muted, small.
Spacing
16/18px padding, 12px header-to-chart, 8px chart-to-caption.
Accessibility
A source caption is mandatory whenever real data is plotted — never presented without attribution.
Print / PDF
Container and its chart are treated as one figure — never split across a page break.
