Navigation

Components that orient a reader inside a document — where they are, what's next, and how the parts relate.

Inherits the MAIM 00 Brand System and SOS Foundation Board. Every rule below is an assembly instruction, not a new design.

COMP-101
Primary Variant

Section Header

Purpose: Opens a major document section (Scope, Pricing, Timeline, Terms). Used on: the first line of any top-level section in a Proposal, SOW, or Report.

02 · Scope of Work
Scope of Work
Layout
Numbered eyebrow above the title; tri-bar spans full content width beneath it, closing the header.
Typography
Eyebrow: JetBrains Mono 500, 10px, tracked, gold. Title: Archivo Black 900, 26px, uppercase.
Spacing
4px between eyebrow and title, 8px between title and tri-bar. 32px clearance before body content starts.
Accessibility
Numbering is textual (02 ·), not decorative — screen readers get section order without relying on layout position.
Print / PDF
Never orphaned — a Section Header cannot be the last line on a printed page; it moves with its first paragraph.
COMP-102
Primary Variant

Subsection Header

Purpose: Breaks a section into named parts. Used on: nested topics inside a Section Header's content — e.g. "Deliverables" inside "Scope of Work".

Deliverables
Layout
Title with a single hairline rule beneath — no eyebrow, no tri-bar. One tier down from Section Header.
Typography
Archivo 600, 17px, sentence case — never uppercase, to visually separate it from Section Header.
Spacing
6px to the rule below; 24px clearance above from the preceding paragraph, 16px below to next content.
Accessibility
Maps to an h3-equivalent in document structure — always nested under a Section Header, never used standalone.
Print / PDF
Keeps with its following line; the hairline never prints alone at the bottom of a sheet.
COMP-103
Primary + Alternates

Divider

Purpose: Separates unrelated blocks without introducing a new heading. Used on: between a table and its footnote, between line items, before a signature block.

Labeled
Layout
Plain hairline is default; labeled variant centers a mono tag; tri-bar variant is reserved for a true section boundary only.
Typography
Labeled variant: JetBrains Mono 500, 9px, tracked, muted ivory — never gold (gold tri-bar already signals boundary elsewhere).
Spacing
16px clearance above and below any divider variant, regardless of context.
Accessibility
Purely visual — carries no semantic heading, so it never replaces a Section or Subsection Header.
Print / PDF
1px hairlines hold at 300dpi print; the mini tri-bar variant never appears smaller than 60px wide.
COMP-104
Primary Variant

Chapter Banner

Purpose: Full-page divider announcing a new major part of a long document. Used on: multi-part deliverables — e.g. splitting an Onboarding Guide into "Getting Started" / "Tools" / "Support" parts.

Part Two
Tools & Access
Layout
Occupies its own full page; centered vertically in the content column, left-aligned text.
Typography
Eyebrow "Part N" in tracked mono; title in Archivo Black 900 at 36px — the largest in-document title after the cover.
Spacing
12px eyebrow-to-title, 14px title-to-tri-bar. Always its own page — never shares a sheet with other content.
Accessibility
Always paired with a Table of Contents entry so the part is reachable without paging through the document.
Print / PDF
Forces a page break before and after; never printed back-to-back with another Chapter Banner.
COMP-105
Primary Variant

Table of Contents

Purpose: Maps a long document's structure up front. Used on: page 2 of any document exceeding six pages — Reports, Delivery Packets, Onboarding Guides.

01Engagement Overview03
02Scope of Work04
03Pricing & Terms07
Layout
Numbered rows, flex-justified: number + title left, page reference right. Hairline between every row.
Typography
Row number in JetBrains Mono, gold; title in Archivo 400, 13px; page reference in muted mono, right-aligned.
Spacing
9px vertical padding per row; 10px gap between number and title.
Accessibility
Entries are real links to their target Section Header when viewed digitally — never decorative text alone.
Print / PDF
Page references reflect final printed pagination, not authoring order — regenerate on export.
COMP-106
Primary Variant

Breadcrumb

Purpose: Shows where the current section sits within the document hierarchy. Used on: below the Compact Header on interior pages of long, multi-part documents.

Statement of Work / Scope of Work / Deliverables
Layout
Single inline row, slash-separated, ordered outermost to innermost. Current level highlighted, rest muted.
Typography
JetBrains Mono 400, 10px, no uppercase — the one navigation label kept in sentence case for legibility at small size.
Spacing
6px around each slash separator; sits with 8px clearance below the Compact Header's hairline.
Accessibility
Current level is bolded in weight as well as gold — never color-only differentiation.
Print / PDF
Optional in print — omit on short (under 6 page) documents where it adds no navigational value.
COMP-107
Primary Variant

Page Marker

Purpose: States position within the total page count. Used on: the footer of every page, paired with the Document Identifier and Confidentiality Label.

Page 4 of 12
Layout
Right-aligned in the footer band, last of the three footer elements (ID, confidentiality, page marker).
Typography
JetBrains Mono 400, 9.5–10px, matching the Document Identifier's footer weight exactly.
Spacing
No internal padding; inherits the footer band's spacing from Footer Family components.
Accessibility
Always states total page count ("of 12"), not just current page — orients a reader holding loose printed sheets.
Print / PDF
Computed at export time from final pagination — never hand-authored, so it can't drift from the printed sheet count.
