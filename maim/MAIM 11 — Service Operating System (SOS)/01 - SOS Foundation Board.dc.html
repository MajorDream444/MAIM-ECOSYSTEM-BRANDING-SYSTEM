Service Operating
System

The reusable operational language for every document produced across AMA, Hanzo, Lux, Major AI Mindset, and affiliated ventures — inherited directly from the MAIM 00 Brand System.

This board defines no new colors, type, or iconography. It arranges MAIM 00's tokens — black foundation, white clarity, gold authority, the tri-bar signature — into the grid and components documents run on. Status roles and data-density type sizes are the only operational extensions, each explicitly derived below.

1 · System Purpose
Consistency
One visual grammar so a receipt, an SOW, and a board memo are unmistakably the same institution.
Assembly
Modular components — header, metadata, cards, tables, approvals — combine rather than redraw per document.
Trust
Executive restraint, clear status and version signals, and verifiable provenance on every page.
2 · Document Design Principles

Principles & the Page Grid

Black leads, gold does the work
≈60% black, 20% white clarity, 12% gold. Culture colors (green/blue/orange) fill the remainder — one per layout, never all five at once.
Tri-bar marks meaning
The green→gold→blue underline marks headlines and section entries only — not a decorative rule.
Every document is traceable
ID, version, status, and owner are always visible — never buried in a footer alone.
Assembled, not authored
Templates are compositions of the components on this board — no bespoke layout per document type.

Light Usage (selective)
White-clarity ground reserved for dense data pages — tables, ledgers, printable exhibits — where black-on-white reads faster at length.
Dark Usage (default)
Black foundation is the default for every cover, header band, section divider, and client-facing page.
