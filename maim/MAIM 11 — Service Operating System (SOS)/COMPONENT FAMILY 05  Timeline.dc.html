Component Family 05

Timeline

Components that show movement through time — schedules, milestones, phases, gates, and how close a deadline is.

Gold marks "now" or "complete"; green signals on-track; orange is reserved for the one deadline that needs attention.

COMP-401
Primary Variant

Timeline

Purpose: Lays out a full engagement's dated waypoints in one horizontal read. Used on: Proposals, SOWs, and Weekly Reports.

Kickoff

09/30
Layout
Equal-width flex segments; connecting line solid gold up to "now", muted ivory beyond it.
Typography
Waypoint label Archivo 600, 11px; date in mono 10px, muted, directly beneath.
Spacing
8px node-to-label; nodes sit on a shared baseline regardless of label length (labels never push nodes off-axis).
Accessibility
Node fill state (solid white=past, solid gold=current, outline=future) is reinforced by the line color change, not fill alone.
Print / PDF
Never split mid-row across a page break — the whole Timeline moves to the next page together.

Milestone Card

Purpose: Expands a single Timeline waypoint into its own detail. Used on: Reports and Delivery Packets, one card per completed or upcoming milestone.

Milestone
07/15/2026
Phase 1 Delivery
Strategic advisory deliverables and implementation support handed off to the client team.
Layout
Gold-bordered card: label row (top), title, short description — same shape as a Highlight Card from Content components.
Typography
Title Archivo 600, 15px; description Archivo 400, 11.5px, muted.
Spacing
16/18px padding, max-width 420px so cards read as discrete units when placed in a grid.
Accessibility
Date always sits with the label, never relegated to a tooltip or hover-only state.
Print / PDF
Treated as a figure — kept whole, never split across a page break.

Progress Bar

Purpose: Shows completion percentage of a single tracked effort. Used on: Weekly Reports and Executive Summaries.

Overall Progress62% · on track
Budget Consumed88% · monitor
Timeline Slippage104% · attention
Layout
Label + status word above a 6px track; fill color communicates state (green=on track, gold=monitor, orange=attention).
Typography
Label Archivo 400, 11px; percentage + status word in mono, right-aligned on the same line as the label.
Spacing
6px between label row and bar; 14px between stacked bars.
Accessibility
The status word (on track / monitor / attention) is mandatory text — the fill color is a reinforcement, never the only signal.
Print / PDF
Track and fill render as distinct grays at minimum; never rely on a subtle color-on-color contrast that vanishes in grayscale.

Gate Indicator

Purpose: Marks a go/no-go checkpoint that blocks progress until cleared. Used on: Timelines and Approval chains where a phase can't start until a condition is met.

Cleared
Pending
Blocked
Layout
Small triangular gate glyph + state word, outlined pill — sits inline on a Timeline or at the head of a Phase Card.
Typography
JetBrains Mono 500, 10.5px, uppercase — matches Status Badge sizing so the two families read as one system.
Spacing
6/14px padding, 8px between glyph and word.
Accessibility
Glyph orientation is identical across states — only color and word change, so meaning is carried by text, not shape.
Print / PDF
Outline weight increases slightly (1.5px) in the print stylesheet to hold visibility at small size on paper.

Primary Variant

Phase Card

Purpose: Groups a span of work with a start, end, and scope summary — one card per phase of a multi-phase engagement. Used on: SOWs and Proposals structuring work into named phases.

Phase 1
06/02 – 07/15
Discovery & Strategic Advisory
Stakeholder interviews, current-state audit, and a strategic roadmap delivered to the client team.
Layout
Eyebrow (phase number) + date range on one line, title beneath, short scope paragraph closes the card.
Typography
Phase eyebrow tracked mono gold; title Archivo 600, 15px; scope Archivo 400, 11.5px muted.
Spacing
16/18px padding, 8px eyebrow-to-title, 6px title-to-scope.
Accessibility
Date range always uses en-dash between two full dates — never abbreviated to avoid ambiguity in print.
Print / PDF
Sequential Phase Cards stack with 12px gaps and share column width — never resized individually.

Deadline Callout

Purpose: Draws attention to a single time-sensitive date. Used on: Proposals with a response window, Invoices nearing due date, Reports flagging a slipping milestone.

5
Days Until Response Deadline
07/15/2026
Layout
Large numeral leads left, label + date stack right — orange-outlined, the only Timeline component permitted a full orange border.
Typography
Numeral in mono 700, 22px; label in tracked mono 9px; date in mono 11px, muted.
Spacing
14/18px padding, 14px gap between numeral and text block, max-width 440px.
Accessibility
Always states the unit ("Days Until…") beside the bare numeral so the number is never ambiguous out of context.
Print / PDF
Reserved for a single use per document — two Deadline Callouts on one page dilute the urgency signal.
