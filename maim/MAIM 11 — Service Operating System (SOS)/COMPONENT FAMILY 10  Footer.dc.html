COMP-901
Primary Variant

Footer

Purpose: The full running band that assembles the other five Footer components into one row. Used on: every page of every document type, no exceptions.

DOC-2026-00417 · v2.3
Confidential — Client & Internal
Page 4 of 12
Layout
3-zone row above a gold hairline: Document Identifier + Version (left), Confidentiality Label (center), Page Number (right).
Typography
All zones in JetBrains Mono 400, 9.5px — the footer is the one place every element shares identical type weight.
Spacing
12px top padding from the hairline; sits inside the page's bottom margin band, never inside the content column.
Accessibility
Repeats identically on every page — a reader holding one loose sheet always has full document identity and handling instructions.
Print / PDF
Bound to the running footer slot; computed once and repeated by the print engine, never hand-placed per page.
COMP-902
Primary Variant

Page Number

Purpose: States position within the total page count — this is the Navigation family's Page Marker (107), reused verbatim as the Footer's right-hand zone. Used on: the right edge of every Footer.

Page 4 of 12
Layout
Right-aligned, last of the Footer's three zones.
Typography
JetBrains Mono 400, 9.5–10px, matching the Document Identifier's footer weight exactly.
Spacing
No internal padding — inherits the Footer's shared spacing.
Accessibility
Always states total page count, not current page alone.
Print / PDF
Computed at export from final pagination — never hand-authored.
COMP-903
Primary Variant

Version

Purpose: The Footer's muted-mono rendering of the Identity family's Version Badge (005) — same data, quieter presentation for repeated use. Used on: immediately after the Document Identifier in every Footer.

DOC-2026-00417 · v2.3
Layout
Inline, no border, joined to the Document Identifier with a middle-dot separator — never boxed like the header-context Version Badge.
Typography
JetBrains Mono 400, 9.5px, muted ivory — deliberately quieter than the bordered Version Badge, since it repeats on every page.
Spacing
No padding; a single middle-dot ( · ) with 4px clearance on each side.
Accessibility
Always the same string as the header's Version Badge — the two must never drift out of sync within one document.
Print / PDF
Muted weight still meets minimum print contrast at 9.5px — verified against grayscale output.

QR Code

Fixed 52×52px square, bordered container, caption to its right explaining the destination.
Typography

Two lines: name/title, then email and phone joined by a middle-dot — never more than these two lines.
