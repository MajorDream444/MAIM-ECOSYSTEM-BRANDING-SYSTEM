Component Family 08

Content

The general-purpose building blocks of a document's body — cards, columns, quotes, and lists.

Where other families carry a specific job (financial, timeline, approval), Content components carry whatever text and structure a page needs.

COMP-701
Primary Variant

Card

Purpose: The default container for grouped content with no specific data role. Used on: any document, wherever a paragraph needs a visible boundary.

Standard Card
A neutral container for a scope item, a note, or a grouped set of facts.
Layout
1px ivory-20% border, no fill, no shadow — the plainest container in the system.
Typography
Title Archivo 600, 14px; body Archivo 400, 12px, muted.
Spacing
16/18px padding; 6px title-to-body gap.
Accessibility
Border alone signals grouping — never relied on as the sole way to convey related content (heading always present).
Print / PDF
1px border holds at any print resolution; card contents never split across a page break.
COMP-702
Primary Variant

Two Column Layout

Purpose: Places two related ideas side by side for comparison or pairing. Used on: before/after comparisons, two signature lines, two linked stats.

Column One
Content occupies equal width, top-aligned by default.
Column Two
The grid gap is the only separator — no vertical rule between columns.
Layout
CSS grid, two equal fractions, 24px gap. No divider line — whitespace alone separates the columns.
Typography
Inherits whatever component sits inside each column — the layout itself sets no type rules.
Spacing
24px column gap is fixed system-wide; never tightened below 20px or content starts to feel cramped.
Accessibility
Reading order is always left-column-first, top-to-bottom — never right column first, even visually.
Print / PDF
Collapses to a single stacked column if either column's content would otherwise force an awkward mid-content page break.
COMP-703
Primary Variant

Three Column Layout

Purpose: Presents three parallel items — pillars, values, service tiers. Used on: Executive Summaries and Proposal cover pages (as seen on the SOS Foundation Board cover itself).

Consistency
One grammar across every document type.
Assembly
Components combine rather than get redrawn.
Trust
Clear status and provenance, every page.
Layout
CSS grid, three equal fractions, 20px gap — slightly tighter than Two Column since each cell carries less content.
Typography
Each cell typically opens with an Archivo 600, 13px label — matches the pattern used on the Foundation Board cover.
Spacing
20px gap; cells are never unequal widths within one instance.
Accessibility
Reads left-to-right, top-to-bottom; never used for more than three items — a fourth forces a new layout, not a fourth column.
Print / PDF
Below 6in content width, collapses to a single column rather than shrinking type past 11px.
COMP-704
Primary Variant

Feature Card

Purpose: Elevates one item above a plain Card — the gold-bordered escalation of COMP-701. Used on: the single most important scope item, stat, or deliverable on a page.

Featured
Feature Card
Reserved for the single figure or decision the reader must not miss on this page.
Layout
Identical geometry to Card, plus a gold border and 6% gold tint, and a "Featured" eyebrow.
Typography
Eyebrow tracked mono, gold, 9px — the only addition versus the standard Card's type stack.
Spacing
Identical to Card: 16/18px padding, max-width 400px.
Accessibility
Never more than one Feature Card per page — stacking gold borders dilutes the emphasis it's meant to carry.
Print / PDF
Tint holds at low-ink print settings, matching the Warning/AI Recommendation tint-contrast standard.
COMP-705
Primary Variant

Summary Box

Purpose: Condenses a long section into a few scannable lines. Used on: the top of Executive Summaries and Weekly Reports, before the detailed body.

In Summary
Phase 1 is on schedule and 62% complete. One risk item (data migration) is blocked pending client input. No budget or timeline changes are proposed.
Layout
Solid white-clarity fill, black text — the one Content component that inverts the page's default polarity.
Typography
Eyebrow in deep gold on white for sufficient contrast; body Archivo 400, 12.5px, black.
Spacing
18/20px padding, max-width 480px — wide enough for 3–4 sentence summaries, no wider.
Accessibility
Black-on-white contrast exceeds 15:1 — the highest-contrast component in the system, appropriate for its lead position on the page.
Print / PDF
Solid fill prints cleanly on any printer — no gradient or tint that could bleed color inconsistently.
COMP-706
Primary Variant

Quote Block

Purpose: Sets off a client testimonial, an executive statement, or a quoted contract clause. Used on: Proposals (testimonials) and Agreements (quoted terms).

"MAIM didn't just deliver a plan — they delivered a team that could execute it."
— A. Whitfield, Aurelia Capital Partners
Layout
Gold left border (2px), no background fill, attribution line beneath in mono, right of nothing — left-aligned like the quote.
Typography
Quote text Archivo 500, 14px — the only body text in the system permitted above 13px outside headings.
Spacing
16/20px padding, 8px between quote and attribution, max-width 480px for readable line length.
Accessibility
Attribution is mandatory — an unattributed quote is never used in a client-facing document.
Print / PDF
Kept whole; quote and attribution never separated by a page break.
COMP-707
Primary Variant

Checklist

Purpose: Tracks discrete, completable items. Used on: Onboarding Guides and Delivery Packets — setup steps, handoff items.

Access credentials issued
Kickoff call scheduled
Layout
14×14px square box + label; checked items fill green and strike through, unchecked stay outline.
Typography
Archivo 400, 12.5px — matches standard body copy exactly, since a checklist is still running text.
Spacing
9px between rows, 10px between box and label.
Accessibility
Strikethrough plus muted color both signal "done" — never fill color alone.
Print / PDF
Boxes print as real checkable squares on a paper copy — the system supports a printed, hand-marked variant identically.
COMP-708
Primary Variant

Bullet List

Purpose: Enumerates non-sequential items with no completion state. Used on: any document body — scope inclusions, feature lists, assumptions.

Stakeholder discovery interviews (up to 6)
Current-state operational audit
Layout
5px gold dot marker, never a dash, asterisk, or default browser bullet.
Typography
Archivo 400, 12.5px — identical to Checklist's body size, since the two are visually paired list types.
Spacing
7px between items — tighter than Checklist's 9px, since bullet items skew shorter on average.
Accessibility
Marked up as a real list (not manually typed dashes) so assistive tech announces item count.
Print / PDF
Gold dot marker holds visible at print resolutions down to 8pt equivalent body size.
