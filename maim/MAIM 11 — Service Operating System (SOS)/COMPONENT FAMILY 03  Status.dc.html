Status Badge

Purpose: States the current lifecycle position of a document or line item in one glance. Used on: headers, metadata blocks, approval chains, and any list of documents or deliverables.

State Logic
Draft — dashed ivory outline, not yet in circulation.
Internal Review — solid gold outline, inside the org.
Client Review — solid blue outline, with the client now.
Approved — solid white-clarity fill, internally cleared.
Completed — solid green fill, work delivered and closed.
Blocked — solid orange outline, needs immediate attention.
On Hold — dashed orange outline, paused, not urgent.
Cancelled — muted outline with strikethrough, terminated.
Layout
Inline pill: 6px status dot + label, never label alone — the dot repeats the state for quick scanning down a list.
Typography
JetBrains Mono 500, 11px, uppercase, 0.08em tracking — identical weight and size across all eight states.
Spacing
5px vertical / 14px horizontal padding; 7px gap between dot and label; 12px minimum gap between adjacent badges.
Accessibility
Every state pairs a distinct border style (solid/dashed/fill/strikethrough) with color — never color as the only signal. Text label is always present, never icon-only.
Print / PDF
Outline and fill states remain distinguishable in grayscale via line weight and fill vs. no-fill; Cancelled's strikethrough is the fallback cue when color desaturates entirely.
