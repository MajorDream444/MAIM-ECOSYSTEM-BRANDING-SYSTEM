Component Family 04

Financial

Components that carry money — pricing, invoicing, receipts, balances, tax, and discount, appearing across nearly every document type.

All figures set in JetBrains Mono, right-aligned, with gold reserved for the single total that matters on a given page.

COMP-301
Primary Variant

Pricing Table

Purpose: Itemizes what's being sold and at what rate. Used on: Proposals, SOWs, and any pre-sale document quoting a scope of work.

Line ItemQtyRateAmount
Strategic Advisory — Phase 11$24,000.00$24,000.00
Implementation Support40 hrs$425.00$17,000.00
Layout
4 columns: description (flexible), qty, rate, amount (fixed, right-aligned). Header row inverts to white-clarity fill.
Typography
Header: Archivo 700, 12px. Description cells: Archivo 400. Numeric cells: JetBrains Mono 400, always right-aligned.
Spacing
9px vertical / 12px horizontal cell padding. Alternating rows tint at 4% ivory, never a hard zebra color.
Accessibility
Header row uses a real `<thead>` — never styled body rows — so assistive tech announces column headers per cell.
Print / PDF
Rows carry `break-inside: avoid`; header repeats if the table spans a page break.
COMP-302
Primary Variant

Invoice Summary

Purpose: Rolls a Pricing Table up to what's actually owed. Used on: Invoices, at the foot of the line-item table.

Subtotal$41,000.00
Tax (0%)$0.00
TOTAL DUE$41,000.00
Layout
Right-aligned card, fixed 280px width, stacked rows: Subtotal → Tax → gold hairline → Total Due.
Typography
Row labels Archivo 400, 12px. Total Due label in Archivo Black 900, 17px — the one moment display weight appears inside a data block.
Spacing
16/18px card padding, 6–10px between rows, 10px clearance around the closing hairline.
Accessibility
Total Due is always the last row and the only bolded one — position and weight both signal finality, not gold alone.
Print / PDF
Card never splits across a page break; if the preceding Pricing Table runs long, this component starts a fresh page.

Payment Schedule

Purpose: Breaks a total into installments over time. Used on: SOWs and Proposals with milestone or retainer billing.

MilestoneDueAmountStatus
DepositOn signing$16,400.00PAID
Phase 1 Delivery07/15/26$24,600.00UPCOMING
Layout
4-column table: milestone, due trigger (date or condition), amount, payment state — state as text, not a badge, to stay compact.
Typography
Due trigger and status in mono, small caps size (10px); status color-coded (green=paid, gold=upcoming, orange=overdue).
Spacing
7–8px cell padding; tighter than Pricing Table since rows are typically fewer and status-scannable.
Accessibility
Status column always spells PAID / UPCOMING / OVERDUE — never a color swatch alone.
Print / PDF
Entire schedule kept on one page where possible; if it must split, the header row repeats.

Typography

Outstanding Balance

Purpose: Flags money still owed. Used on: Invoices with partial payment, statements, and reminder documents.

Balance Due
$24,600.00
Past Due
$24,600.00 · 12 days
Layout
Standalone card; Past Due alternate adds a day-count, always paired, never the amount alone.
Typography
Balance figure in mono 700, 18px; label above in tracked mono 9px, matching the color of its border (gold vs. orange).
Spacing
14/18px card padding; 16px gap when Balance Due and Past Due appear side by side.
Accessibility
Past Due always states the day count in text — never orange color as the sole urgency signal.
Print / PDF
Past Due variant is the one Financial component permitted to repeat in a footer strip on reminder documents.

Tax Summary

Purpose: Itemizes tax lines when more than a flat rate applies. Used on: Invoices and Receipts in multi-jurisdiction or multi-rate engagements.

State Sales Tax (7.25%)$2,972.50
Local Surcharge (1%)$410.00
Layout
Compact 2-column list, no header row — always nested directly above or inside an Invoice Summary, never standalone.
Typography
Jurisdiction/rate label in Archivo 400, 11.5px, muted; amount in mono, right-aligned, full opacity.
Spacing
7px row padding — the tightest row spacing in the Financial family, since it's a supporting detail, not a headline figure.
Accessibility
Rate is always stated in the label text (7.25%) — never omitted in favor of the dollar figure alone.
Print / PDF
Never separated from the Invoice Summary it feeds — both stay on the same printed page.

Primary Variant

Discount Block

Purpose: Shows a reduction applied to a total, and why. Used on: Proposals and Invoices with negotiated, loyalty, or promotional pricing.

Loyalty Discount — 10%
– $4,100.00
Layout
Single row, green-outlined, reason on the left, signed negative amount on the right.
Typography
Reason in tracked mono 9px; amount in mono 14px, always prefixed with an en-dash minus, never parentheses.
Spacing
10/16px padding, max-width 400px — a discount is a line item, not a headline block.
Accessibility
Green is the one place in Financial components a culture accent (Jamaican Green) is explicitly permitted — signals a favorable adjustment.
Print / PDF
Sits directly above the line it discounts in the Pricing Table or Invoice Summary — never floats separately.
COMP-308
Primary Variant

Currency Block

Purpose: States which currency governs a figure or a whole document, for cross-border engagements. Used on: the metadata block or table header of any non-USD document.

Figures in USD unless noted
Layout
Single inline tag, placed once per document — in the metadata block if global, or a table header note if mixed.
Typography
JetBrains Mono 400, 11px; the currency code itself in full-opacity ivory, surrounding text muted.
Spacing
4px vertical / 12px horizontal padding, matching the Version Badge's proportions for family consistency.
Accessibility
Currency is always spelled as a 3-letter ISO code (USD, EUR) — never a symbol alone, which can be ambiguous ($ vs. other dollar currencies).
Print / PDF
If a document mixes currencies, every affected table repeats its own Currency Block in the header — never assumed from page 1 alone.
